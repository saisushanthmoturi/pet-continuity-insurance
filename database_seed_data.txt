PART 3: SAMPLE REST API JSON PAYLOADS (FOR TESTING VIA POSTMAN / CURL)
================================================================================

1. AUTHENTICATION (POST /api/auth/login)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/auth/login
Method:   POST
Headers:  Content-Type: application/json

Payload:
{
  "email": "susan.miller@example.com",
  "password": "password123"
}

Expected Response:
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "email": "susan.miller@example.com",
  "role": "CUSTOMER",
  "userId": 2
}
(Also sets HttpOnly cookie: jwt_token=<token>; Path=/; SameSite=Lax)


2. REGISTER PET (POST /api/pets)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/pets
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CUSTOMER_OR_ADMIN_JWT_TOKEN>

Payload:
{
  "customerId": 1,
  "name": "Cooper",
  "species": "Dog",
  "breed": "Labrador Retriever",
  "age": 3,
  "weight": 28.5,
  "gender": "MALE",
  "estimatedAnnualCareCost": 1300.0
}


3. ADD MEDICAL RECORD (POST /api/pets/{petId}/medical-records)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/pets/1/medical-records
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CUSTOMER_OR_ADMIN_JWT_TOKEN>

Payload:
{
  "petId": 1,
  "conditionName": "Bilateral Ear Infection Cleared",
  "diagnosisDate": "2024-05-12",
  "treatmentPlan": "Otic drops 7 days. Resolved.",
  "estimatedAnnualMedCost": 95.0
}


4. REQUEST ACTUARIAL QUOTE (POST /api/underwriting/quotes)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/underwriting/quotes
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CUSTOMER_OR_ADMIN_JWT_TOKEN>

Payload:
{
  "customerId": 1,
  "petId": 1,
  "requestedCoverage": 25000.0
}


5. PURCHASE / CREATE POLICY (POST /api/policies)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/policies
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CUSTOMER_OR_ADMIN_JWT_TOKEN>

Payload:

  "quoteId": 1
}


6. SIMULATE PREMIUM PAYMENT (POST /api/payments/premium)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/payments/premium
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CUSTOMER_OR_ADMIN_JWT_TOKEN>

Payload:

  "paymentMethod": "SIMULATED_CARD",
  "simulateFailure": false
}


7. FILE OWNER DEATH CLAIM (POST /api/claims)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/claims
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CUSTOMER_OR_ADMIN_JWT_TOKEN>

Payload:
{
  "policyId": 1,
  "claimantName": "Sarah Miller",
  "relationship": "SISTER",
  "deathCertificateNo": "DC-OR-2026-88712",
  "dateOfDeath": "2026-09-14",
  "notes": "Policyholder Susan Miller passed away in hospital. Requesting activation of continuity fund for Barnaby."
}


8. APPROVE CLAIM (POST /api/claims/{claimId}/approve)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/claims/1/approve
Method:   POST
Headers:  Authorization: Bearer <CLAIMS_OFFICER_OR_ADMIN_JWT_TOKEN>

(Triggers fraud check, verifies policy is active, approves claim, creates $25,000 Pet Continuity Fund in PaymentFundService, and updates policy status to CLAIM_FILED)


9. SUBMIT PET CARETAKER VERIFICATION (POST /api/care/verifications)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/care/verifications
Method:   POST
Headers:  Content-Type: application/json
          Authorization: Bearer <CARETAKER_OR_ADMIN_JWT_TOKEN>

Payload:
{
  "petId": 1,
  "caretakerId": 1,
  "verificationDate": "2026-09-16",
  "notes": "Monthly check-in: Golden Retriever Barnaby is healthy, happy, active. Food supplies stocked."
}


10. DISBURSE MONTHLY PET ALLOWANCE (POST /api/funds/{fundId}/disburse)
--------------------------------------------------------------------------------
Endpoint: http://localhost:8080/api/funds/1/disburse?petId=1&caretakerId=1
Method:   POST
Headers:  Authorization: Bearer <CARETAKER_OR_ADMIN_JWT_TOKEN>

(Checks caretaker verification eligibility via CareVerificationService, deducts $300-$350 monthly maintenance allowance from Pet Continuity Fund, and logs transaction)
